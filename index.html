Welcome to the Acoular Organization!#

The Acoular Organization develops open source solutions for (acoustic) beamforming and sensor array signal processing. Acoular currently offers:

  • Acoular: Our flagship Python package for beamforming, deconvolution, source localization and mapping.

  • SpectAcoular: Custom graphical user interfaces for Acoular using the Bokeh visualization library.

  • AcouPipe: Toolbox for generating microphone array data with Acoular for deep learning tasks.
