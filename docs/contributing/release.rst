.. _Release Policy:

Release policy
==============

Release workflows can differ by package.
Use the relevant package tab below.

.. tab-set::
   :sync-group: package

   .. tab-item:: Acoular
      :sync: acoular

      From Acoular version 24.05 onwards, the plan is to make a new release every three months.
      Upcoming releases are tracked with a corresponding `milestone <https://github.com/acoular/acoular/milestones?state=open>`_.
      A pull request must be fully merged before the milestone is closed to be included in that release.
      Source code can only be merged if it meets the :ref:`Code Quality Standards`.

   .. tab-item:: SpectAcoular
      :sync: spectacoular

      SpectAcoular currently does not publish a separate release policy on this website.
      For release planning, check the `milestones <https://github.com/acoular/spectacoular/milestones>`_ and coordinate with the maintainers in the repository.
