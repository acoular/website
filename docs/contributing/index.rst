Contributing
============

Thank you for considering contributing to an Acoular package.
There are many ways to contribute, and we appreciate all of them:

- **Report issues**: If you find a bug in a package or its documentation, please open an issue in that package's repository on GitHub.
- **Take part in discussions**: You can join the `Acoular organization discussions <https://github.com/orgs/acoular/discussions>`_ or use a package repository's discussion and issue pages to ask questions and discuss ideas.
- **Contribute code or documentation**: Fork the repository of the package you want to improve and :doc:`submit a pull request <pull_request>`. Small fixes are just as welcome as larger features.
