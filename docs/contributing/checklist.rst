Contribution checklist
======================

Before submitting a pull request, please make sure you have done the following:

Common checklist
----------------

- [ ] Read the shared :doc:`index` guide.
- [ ] Read the package-specific instructions relevant to your change.
- [ ] Ensure your branch is up to date with the upstream repository.
- [ ] Verify that the :doc:`quality` standards are fulfilled.
- [ ] Update documentation when behavior, APIs, or workflows changed.
