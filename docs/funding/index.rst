Funding
=======

Acoular's development is supported by the following funding bodies.

- `Deutsche Forschungsgemeinschaft (DFG) <https://gepris.dfg.de/project/528753521>`_: This DFG-project (project no. 528753521) aims to expand Acoular's user base to related fields such as robotics, ultrasound, and hydroacoustics, and to create a sustainable foundation for future community-based development. Planned work includes improving the continuous integration process with better code test coverage to strengthen quality assurance and reproducibility of results; refactoring several submodules to enable new use cases and interfaces to other research software; developing stricter release and deprecation strategies as well as contributor guidelines; expanding the documentation with significantly more worked examples and benchmark datasets; and expanding training offerings for potential users.
